The messages the library prints, such as usage errors and deprecation warnings,
come from a catalogue and can be translated. English is built in and is the
fallback for every other language.

## Picking the user's language

`cli.SelectLocalizer` reads `LC_ALL`, `LC_MESSAGES`, `LANG` and `LANGUAGE`,
following the same rules as GNU gettext, and returns the catalogue that best
matches:

```go
cmd := &cli.Command{
	Name:      "greet",
	Localizer: cli.SelectLocalizer(os.LookupEnv, de.Catalog),
}
```

An exact tag match wins over a language-only match, so a `pt-BR` user gets a
`pt-BR` catalogue when one is available and a `pt` one otherwise. When no
catalogue matches, `cli.English` is used.

To translate every command at once, set the package-level default instead:

```go
cli.DefaultLocalizer = cli.SelectLocalizer(os.LookupEnv, de.Catalog)
```

## Writing a catalogue

A `cli.Catalog` is a map from a stable key to a message. Keys are listed by
`cli.Keys`. Placeholders are written in braces, and a message can provide
plural forms:

```go
var Catalog = &cli.Catalog{
	Tag:    "fr",
	Plural: cli.OneOther,
	Messages: map[string]cli.Text{
		"error.unknown_flag": {Other: "option inconnue : {flag}"},
		"error.required_flag": {
			One:   "option obligatoire manquante : {flag}",
			Other: "options obligatoires manquantes : {flag}",
		},
	},
}
```

A catalogue only needs the keys it wants to change; anything it leaves out
falls back to English, so a partial translation is usable. `Plural` picks the
form for a count, and `cli.OneOther` covers languages that only distinguish one
from many.

## Loading translations from files

Import `github.com/urfave/cli/v3/i18n` to load catalogues from JSON, for
example ones embedded with `go:embed`:

```go
c, err := i18n.Load(os.DirFS("locales"), "fr.json", "fr", cli.OneOther)
if err != nil {
	return err
}
cmd.Localizer = c
```

```json
{
  "error.unknown_flag": "option inconnue : {flag}",
  "error.required_flag": {"one": "option obligatoire manquante : {flag}", "other": "options obligatoires manquantes : {flag}"}
}
```

`i18n.Missing` reports the keys a catalogue does not translate, which makes it
easy to test that a translation is complete.

## Error values stay English

An error returned from `Run` always reports English through its `Error` method,
so that callers can match on its text. To render it in the command's language,
use `cmd.Localize`:

```go
if err := cmd.Run(ctx, os.Args); err != nil {
	fmt.Fprintln(os.Stderr, cmd.Localize(err))
}
```

Errors the library did not create are returned unchanged.
